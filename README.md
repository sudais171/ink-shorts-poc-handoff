# ink-shorts-poc-handoff

Handoff of the **Ink Shorts `_poc` 3D environment pipeline**: Blender-scripted stylised props and rooms + a
modified three.js toon renderer, with the existing 2D Ink Shorts characters placed inside. Two finished
environments: a **saloon/parlour** and a **courtroom** (judge picks up a gavel, strikes twice, puts it down).
Nothing here is integrated into the main Ink Shorts Studio plugin.

**Start with [`_poc/handoff/README.md`](_poc/handoff/README.md)**, then the other eight documents in `_poc/handoff/`:
`ARCHITECTURE.md`, `PIPELINE.md`, `ASSETS.md`, `INTERACTIONS.md`, `QA.md`, `PERFORMANCE.md`, `INTEGRATION.md`, `FILE_MAP.md`.

## Repository layout
```
_poc/                         the production system (engine copy, Blender scripts, scenes, layouts, generated models/textures)
  handoff/                    the nine documents
  engine/                     modified Ink Shorts engine (set3d.js, character.js, player.js) + three r159 + converted GLTF loader
  *.py                        Blender build scripts (props, rooms) and contact-sheet scripts
  court/  scene3/             courtroom and saloon scene pages + baked room .glb files
  turntable/  lightbox/       inspection pages
  assets2/                    generated painted textures
  downloads/hero, downloads/court   generated prop models (.glb)
ink-shorts-studio/kit/tools/render.mjs   the renderer, an unmodified copy from the main plugin (v1.1.0), at the path the scenes expect
```

## Requirements
| Need | Version used | For |
|---|---|---|
| Node.js | v24.20.0 (ES modules; any recent LTS should work) | `render.mjs` |
| Google Chrome or Microsoft Edge | installed in the default location, or set `CHROME_PATH` | headless rendering (WebGL; GPU used if present) |
| ffmpeg | 9.0.2 (on PATH, or set `FFMPEG`) | video encoding (stills don't need it) |
| Blender | **4.2 LTS** (4.2.23 used), portable zip: https://download.blender.org/release/Blender4.2/blender-4.2.23-windows-x64.zip | only to **rebuild** props/rooms; unzip to `_poc/tools/` |
| Python 3 + Pillow | 3.12 + Pillow 13.0.0 | only the contact-sheet scripts |

No `npm install` is needed: the engine is plain scripts loaded by `index.html`; `render.mjs` uses only Node built-ins.
Tested on Windows 11 (Intel HD 520). Scene pages are opened through `file://`; `render.mjs` passes `--allow-file-access-from-files`.

## Render the two scenes (no Blender needed: baked rooms are included)
```bash
cd _poc/court
node ../../ink-shorts-studio/kit/tools/render.mjs --page index.html --query "cam=g&ti=0" --stills "1.8" --quality 1080 --frames-dir out/check
node ../../ink-shorts-studio/kit/tools/render.mjs --page index.html --query "cam=move" --from 0 --to 13 --quality 1080 --out out/court.mp4

cd ../scene3
node ../../ink-shorts-studio/kit/tools/render.mjs --page index.html --query "set=hero5&cam=b&lm=mix" --stills "2.6" --quality 1080 --frames-dir out/check
node ../../ink-shorts-studio/kit/tools/render.mjs --page index.html --query "set=hero5&cam=through" --from 0 --to 6 --quality 1080 --out out/saloon.mp4
```
`--quality 540` renders a quick half-size check. All scene parameters: `_poc/handoff/PIPELINE.md`.

## Rebuild props and rooms (needs Blender in `_poc/tools/`)
```bash
cd _poc
B=tools/blender-4.2.23-windows-x64/blender.exe          # on macOS/Linux point B at your Blender 4.2 binary
$B -b --factory-startup -P court_props.py               # courtroom props  -> downloads/court/*.glb
$B -b --factory-startup -P build_court.py -- 32         # courtroom room   -> court/room_court.glb, tops_court.json  (~2-2.5 min)
$B -b --factory-startup -P heroes.py                    # barrel, lantern (+ unused round-4 table/chair)
$B -b --factory-startup -P heroes3.py                   # table3, chair3, sideboard
$B -b --factory-startup -P heroes4.py                   # crate, candlestick, frame, chandelier, sconce
$B -b --factory-startup -P jug5.py                      # jug
$B -b --factory-startup -P build_room3.py -- 32 hero5 ao   # saloon room -> scene3/room_hero5_ao.glb, tops_hero5.json (~70 s)
```
Scripts locate their folder from their own path (no fixed drive paths).

## Known limitations and missing files
- **Not included**: Blender (951 MB, download link above); all render outputs and comparison sheets; third-party
  downloads (`downloads/kk`, `downloads/ph`, `downloads/st`); baked rooms of earlier rounds (the saloon page still
  lists sets `kk/ph/st/hero..hero4`, which will fail to load; use `set=hero5`); the reference-video frames used by
  the `sheets*.py` scripts (`refs/` - copyrighted YouTube frames, not redistributable).
- **Texture generators were not saved**: `_poc/assets2/*.png` were made with inline PIL snippets; the PNGs are here,
  the code that made them is not.
- The saloon's jug interaction uses an older method (rig-derived hand + drawn fist) than the courtroom's gavel.
- `engine/set3d.js` contains superseded code paths and a debug mode (`outl > 5`).
- 2D-character limits (flat cards, fixed vs camera-facing, the 3D stick arm for the judge only): `_poc/handoff/INTERACTIONS.md`.
- Unresolved items: `_poc/handoff/QA.md`.
